# Zerodha Clone 🪙

A full-stack clone of the Zerodha trading platform — built with the MERN stack.  
Includes a landing page, signup/login, dashboard, holdings, positions, orders, and funds management.

> ⚠️ This project is for **educational purposes only**. Not affiliated with Zerodha.

## ✨ Features

- 🔐 User authentication (JWT based)
- 📊 Dashboard with live holdings & positions
- 📈 Buy / Sell orders
- 💰 Funds management
- 📱 Fully responsive UI
- 🌙 Clean Zerodha-inspired design

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- React Router
- Axios
- Bootstrap / Material UI

**Backend**
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- bcrypt for password hashing

**Tools**
- Git & GitHub
- Postman
- VS Code
